# Glossary

| Term | Definition |
| ------ | ------------ |
| **Highscore** | number of correct country guesses in a row by a player |
| **Headless Frontend** | A frontend that contains no business logic and only renders data received from the backend |
| **JSON Web Token (JWT)** | A compact, signed token used to authenticate users in a stateless manner |
| **restcountries.com** | A free public REST API that provides country data including names, flags, and other metadata |
| **FastAPI** | A modern Python web framework for building APIs, with automatic OpenAPI documentation |
| **Vue 3** | A progressive JavaScript/TypeScript frontend framework |
| **PostgreSQL** | An open-source relational database used to persist user accounts and highscores |
| **ADR (Architecture Decision Record)** | A document capturing an important architectural decision, its context, and its consequences |
